# Blender model integration

The browser viewer loads the project-authored reference model from `frontend/public/models/turbine.glb`. This is a conceptual visualization, not an OEM drawing or dimensionally accurate assembly. The editable scene is `models/ge_6b03_reference.blend`, generated by `models/build_ge_6b03_reference.py`. See the [public-data review](GE_6B03_PUBLIC_DATA_REVIEW.md) for sources, which public dimensions are stored as metadata, and the model's limits.

## Component mapping

The part inspector has six stable semantic component IDs:

| Component | `component_id` | Recognized object-name examples |
| --- | --- | --- |
| Inlet | `inlet` | `inlet`, `intake`, `air_entry` |
| Compressor | `compressor` | `compressor`, `comp_stage`, `compressor_casing` |
| Combustor | `combustor` | `combustor`, `combustion`, `combustion_chamber` |
| Turbine | `turbine` | `turbine`, `turbine_stage`, `turbine_casing` |
| Shaft | `shaft` | `shaft`, `rotor`, `spool` |
| Generator | `generator` | `generator`, `alternator` |

Assign the exact `component_id` custom property to each component mesh or parent object. The loader also recognizes the listed names on objects and parents. Keep components that need separate selection under separate parents; a merged mesh cannot provide reliable per-component selection. Unmapped geometry remains visible but does not update the inspector when clicked.

For sub-part inspection, keep each physical part as a separate Blender object. Export custom properties/extras so the component mapping and reference metadata survive. Keep metadata scope explicit: for example, a bucket envelope describes one bucket item, while a nozzle reference may describe a full stage. Do not relabel stage data as dimensions or mass for an individual vane. Keep geometry caveats beside public reference values.

## Export and Meshopt compression

1. Center the assembly and make the flow path clear. The viewer centers and scales the imported scene.
2. Export using Blender's glTF 2.0 exporter as an uncompressed GLB. Enable custom properties/extras.
3. Run the same high-level Meshopt post-export step used for the project asset. The output must contain `EXT_meshopt_compression` and `KHR_mesh_quantization`:

   PowerShell:

   ```powershell
   npx --yes @gltf-transform/cli@4.2.1 meshopt frontend/public/models/turbine.glb "$env:TEMP\turbineiq-turbine-meshopt.glb" --level high
   python docs/redesign/phase5/dump_glb_names.py frontend/public/models/turbine.glb "$env:TEMP\turbineiq-source-names.json"
   python docs/redesign/phase5/dump_glb_names.py "$env:TEMP\turbineiq-turbine-meshopt.glb" "$env:TEMP\turbineiq-meshopt-names.json"
   Compare-Object (Get-Content "$env:TEMP\turbineiq-source-names.json") (Get-Content "$env:TEMP\turbineiq-meshopt-names.json")
   ```

   POSIX shell:

   ```sh
   npx --yes @gltf-transform/cli@4.2.1 meshopt frontend/public/models/turbine.glb "$TMPDIR/turbineiq-turbine-meshopt.glb" --level high
   python docs/redesign/phase5/dump_glb_names.py frontend/public/models/turbine.glb "$TMPDIR/turbineiq-source-names.json"
   python docs/redesign/phase5/dump_glb_names.py "$TMPDIR/turbineiq-turbine-meshopt.glb" "$TMPDIR/turbineiq-meshopt-names.json"
   diff -u "$TMPDIR/turbineiq-source-names.json" "$TMPDIR/turbineiq-meshopt-names.json"
   ```

   The comparison must show no differences in node, mesh, material, or animation names and counts. Do not replace the project asset if the contract differs. After review, replace the local GLB with the validated Meshopt output when compression is intended.

The commands above use the project CLI version and write the trial to a temporary directory. The project stores one GLB, not a second copy. The runtime viewer uses the Meshopt decoder bundled with its existing Three/Drei dependency and does not request a decoder from a CDN. An uncompressed Blender GLB remains supported and loads without either compression extension.

## Viewer behavior

The viewer supports orbit, pan, zoom, camera reset, component selection, isolation, explosion, and opt-in visual rotor motion. Rotor motion is illustrative and is not tied to scenario data or actual RPM. Reduced-motion preference disables the rotor and camera easing. The mesh-name contract and part-selection behavior are documented in the [Phase 5 report](redesign/PHASE5.md).

## Review checklist

- Verify the six component IDs and representative object-name aliases.
- Verify that part-level objects remain separately selectable where needed.
- Confirm public metadata has correct component/part scope and visible caveats.
- Compare node, mesh, material, and animation names/counts before and after compression.
- Load both the compressed project asset and an uncompressed test export; verify selection, reset, isolation, explosion, theme change, and rotor toggle.
