# Synthetic demonstration scenarios

Every row generated by `turbineiq.synthetic.generate_scenario` is marked `synthetic_data=True`. The 15-minute timeline starts at a fixed timestamp so a selected scenario and seed reproduce the same frame. No external data is loaded.

## Scenarios

- **Baseline:** fixed study inputs with gentle synthetic ambient temperature and pressure variation.
- **Warmer ambient:** ambient temperature is shifted upward. Inlet mass flow follows an explicit fixed-volume density assumption, so output trends change through the cycle calculation.
- **Compressor-performance drift:** compressor efficiency is gradually shifted from its study value to a lower value. This is a controlled model perturbation, not a validated fault signature.
- **Power-sensor spike:** the deterministic cycle result stays unchanged; one observed electrical-power measurement receives a labelled synthetic spike.

The generated observations include both `model_electrical_power_kw` and noisy `observed_electrical_power_kw`; their difference is `power_residual_kw`. Seed controls the small measurement noise and the exact fault point is fixed by scenario length.

## Limits

The scenarios demonstrate repeatability, model integration, and analytics behavior only. They are not a statistical representation of a real turbine, not an OEM operating envelope, and not evidence that a real failure presents the same pattern. All numeric inputs are editable assumptions.
